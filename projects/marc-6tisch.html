MARC-6TiSCH: Churn-Bounded Rescheduling Control for Sustainable Mobile 6TiSCH Networks

Raziur Rahman • Nikumani Choudhury • Wei Xiang

6TiSCH TSCH Mobile IoT Rescheduling Control 6P Stale Cells

Overview

MARC-6TiSCH is a mobility-aware rescheduling-control framework for 6TiSCH networks that regulates when schedule reconfiguration should be invoked, deferred, or suppressed under changing network conditions.

The framework jointly considers link reliability, queue pressure, stale-cell age, parent-switching activity, and recent 6P operations to maintain responsive scheduling while preventing excessive reconfiguration churn.

Key Highlights

  • Distributed churn-bounded rescheduling control
  • Mobility-aware stale-cell detection and release
  • Bounded 6P reconfiguration overhead
  • HOLD, PREPARE, RELEASE, and THROTTLE control actions
  • Compatible with standard RPL, 6top, 6P, and TSCH mechanisms
  • Improved reliability, latency, radio efficiency, and queue performance
