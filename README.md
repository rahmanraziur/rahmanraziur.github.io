# Raziur Rahman · Academic Website

Source for **[rahmanraziur.github.io](https://rahmanraziur.github.io)**, the academic website of Raziur Rahman, a joint PhD researcher at BITS Pilani, Hyderabad Campus (India), and La Trobe University, Melbourne (Australia), under the ASCRIN joint PhD programme.

My research is on adaptive scheduling and resource allocation for 6TiSCH-based smart-city IoT networks: keeping low-power multi-hop networks scalable, energy-efficient and reliable as traffic surges, deadlines tighten and devices move.

## What's on the site

- **Home**: an animated 6TiSCH slotframe (16 channel offsets with channel hopping), followed by About, Publications, Teaching, Service and tools, the LUMEN-X Lab, Education and Contact.
- **Live network**: a browser simulation of a smart-city 6TiSCH network with emergency-vehicle priority, fire-event traffic bursts and multi-hop forwarding.
- **Project pages**: one page per paper with an overview and key results.
- **Study room**: a Pomodoro timer with focus music and rotating research quotes.

## Repository layout

```
index.html            Homepage (styles, scripts and images inlined)
projects/             One page per publication
assets/css/style.css  Stylesheet for the project pages
assets/images/        Profile photo, lab logo, favicon
focus/                Study room (Pomodoro timer)
quotes.html           Quote rotator embedded in the study room
sitemap.xml           Sitemap for search engines
robots.txt            Crawler rules
```

The site is plain HTML, CSS and JavaScript with no build step, served by GitHub Pages from the `main` branch. To preview it locally, open `index.html` in a browser, or run `python3 -m http.server` in the repository root and visit `http://localhost:8000`.
